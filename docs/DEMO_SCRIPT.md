# Demo script (90 seconds)

Owner: Dev C. Rehearse twice before presenting.

1. **Hook (15s)** Egyptians abroad sent home a record amount last year, and the
   households receiving it still cannot borrow. Transfers do not build a credit file.
2. **Show EG-0007 (25s)** Steady inflows from the Saudi corridor. Score 78, tier B.
   Point at the four bars. Read the Arabic explanation out loud.
3. **Show EG-0142 (25s)** Same amount of money, arriving erratically. Score 41.
   Same four bars, different shape. Note that the reason is stated, not hidden.
4. **The IBM layer (15s)** The score and both explanations are deterministic,
   so the judges can re-run them. IBM Granite runs locally on Ollama under
   Apache 2.0 and can reword the explanation, never the score - it is off for
   this demo. Open `api/audit.log` and the model card: every decision is one
   JSON line with its features, weights and model version, so the Central Bank
   can reproduce it. Fully offline, no keys, no hosted inference.
5. **Close (10s)** Egypt already moves the money. We make the money count as proof.
